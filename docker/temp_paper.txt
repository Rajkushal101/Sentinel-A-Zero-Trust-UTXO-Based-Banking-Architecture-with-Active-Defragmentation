Abstract
:
 
In an era dominated by the Internet of Things (IoT) and interconnected devices, securing these devices has become a significant challenge. A major problem is the users' limited understanding of the specific security protocols required for their devices. Consequently, individuals often 
fail to
 implement 
appropriate security
 settings in their devices, which can result in potential breaches of personal data, unauthorized access, or even large-scale network attacks. To address this issue, Anveshan has been developed as a sophisticated web application aimed at simplifying the process of securing networking and IoT devices for users. The application employs AI-powered image recognition technology to 
identify
 device types based on user-uploaded photos. It then provides customized instructions for configuring security settings specific to the recognized device, maximizing protection. Additionally, the application incorporates an interactive chatbot that provides detailed, sequential instructions for implementing these security protocols and responds to user inquiries related to device security. Anveshan's user-friendly interface makes it accessible to individuals with varying levels of technical 
expertise
, ensuring that even those with limited knowledge can effectively secure their devices. The application's artificial intelligence-based method not only simplifies the process of configuring security settings but also customizes device security setup for users. By empowering users to take control of their device security, Anveshan contributes to a safer digital ecosystem and reduces the risk of cyber-attacks on both individual and network levels.
Keywords: 
IoT security, AI-powered image recognition, device security protocols, interactive chatbot, user-friendly interface, cybersecurity, personalized security settings, network attack prevention
Introduction 
The widespread adoption of Internet of Things (IoT) technology has revolutionized how people and organizations engage with digital systems [1] [2]. Connected devices, ranging from household gadgets to industrial control mechanisms, have become essential components of contemporary digital frameworks. However, this heightened connectivity has also introduced a significant security risk, as many users lack the necessary knowledge to implement proper security measures for their devices [3]. Cybercriminals frequently take advantage of inadequate or improperly configured security measures, resulting in unauthorized entry, information leaks, and extensive network intrusions [4]. 
To bridge this gap, there is an urgent demand for user-friendly tools that streamline the process of securing IoT and networking devices. This study presents Anveshan, an artificial intelligence-powered web platform designed to bolster device security through visual recognition and interactive guidance. By automatically detecting device types from user-submitted images and offering customized security configurations, Anveshan enables users to effectively protect their devices. Anveshan leverages advanced computer vision techniques to analyze device images and identify specific models or categories. Once a device is recognized, the platform provides step-by-step instructions tailored to that particular device's security requirements. These instructions cover essential aspects such as firmware updates, password management, and network configuration, ensuring comprehensive protection against common vulnerabilities.
A notable aspect of Anveshan is its incorporation of a smart chatbot that improves user experience by providing detailed, sequential security implementation assistance. The chatbot not only delivers comprehensive, step-by-step instructions for setting up security measures but also addresses user questions in real-time, ensuring clear and straightforward implementation. By enabling users to pose specific security-related inquiries and receive immediate guidance, the chatbot makes device security more accessible to individuals. This interactive feature significantly reduces the learning curve associated with implementing complex security protocols, making it easier for users of all technical backgrounds to secure their devices effectively. The chatbot's ability to provide contextual information and clarify doubts on the spot helps users make informed decisions about their security settings, leading to more robust protection overall. Furthermore, by offering a personalized and responsive approach to security guidance, Anveshan's chatbot fosters greater user engagement and encourages consistent adherence to best security practices. This research explores Anveshan's design, functionality, and influence on user security practices. Through its AI-driven approach, the application not only simplifies device security but also promotes a safer digital landscape by mitigating cybersecurity threats.

System Architecture and Implementation
 
Fig. 1 illustrates the architecture of Anveshan, a web application designed to simplify device security through AI-powered image recognition and a conversational chatbot. The system architecture is built around a modular design, enabling seamless integration of various components to achieve its goal of 
providing
 customized security guidance.
 
Fig.1: 
System architecture of Anveshan, designed to streamline security measures for device-specific applications
1. User Interface (UI):
The application's front-end is developed using Python's Streamlit framework, chosen for its ability to create interactive and user-friendly web interfaces rapidly. This allows users with varying technical expertise to easily navigate and utilize Anveshan's features. The UI guides users through the process of uploading device images and interacting with the chatbot, ensuring a smooth and intuitive experience.
2. Image Hosting and Management:
Upon uploading a device image (e.g., smartphone, router, IoT device), the application utilizes ImgBB, a cloud-based image hosting service. ImgBB generates a publicly accessible URL for the uploaded image, facilitating its accessibility for subsequent processing by the Pixtral model. This step ensures efficient image management and streamlined data flow within the system.
3. Pixtral Model for Device Recognition:
The core of Anveshan's device identification capability lies in the Pixtral model. This computer vision model is trained to recognize and classify a wide range of devices based on their visual features. By analyzing the image URL provided by ImgBB, Pixtral accurately identifies the brand and model of the uploaded device. This identification process is crucial for providing tailored security recommendations.
4. Fine-Tuned Mistral Model for Chatbot and Security Guidance:
The identified device information is then passed to a fine-tuned Mistral Large Language Model (LLM). This LLM serves two primary functions: providing tailored security guidance and powering the interactive chatbot.
Fine-Tuning via Hugging Face: The Mistral model is fine-tuned using Hugging Face's pre-trained models and tools.
This customization process enhances the model's ability to deliver 
accurate
 and relevant security recommendations.
Device Dataset Integration: The Mistral model accesses a comprehensive device dataset containing information about various devices, including their brands, models, firmware versions, known vulnerabilities, and security best practices. This dataset enables the model to check for exact device matches and retrieve pertinent security information.
Security Recommendation Generation: 
Exact Match: If an exact match is found in the device dataset, the Mistral model provides precise, device-specific security recommendations, such as firmware updates and vulnerability alerts.
Generalized Recommendations: In cases where an exact match is not found, the model leverages learned patterns and similarities to generate generalized security recommendations based on comparable devices.
Interactive Chatbot: The Mistral model also powers the application's chatbot. Users can interact with the chatbot to ask security-related questions about their devices. The chatbot processes these queries and generates responses, dynamically refining them based on follow-up questions and additional context.
5. System Workflow:
Image Upload: The user uploads an image of their device via the UI.
Image Hosting: The image is hosted on ImgBB, generating a public URL.
Device Recognition: The Pixtral model analyzes the image URL to identify the device's brand and model.
Security Guidance: The identified information is sent to the fine-tuned Mistral model. 
The model checks the device dataset for an exact match.
If an exact match is found, precise security recommendations are provided.
If no exact match is found, generalized recommendations are generated.
Chatbot Interaction: The user interacts with the chatbot for further security assistance.
Response Delivery: Tailored or generalized security guidance and chatbot responses are returned to the user through the UI.
   
Results
Case 1: Apple Watch Series 6
Upon uploading an image of the Apple Watch Series 6
 (fig.2)
, Anveshan successfully 
identified
 the device and presented a set of specific security measures relevant to this model. These recommendations included “enabling strong passcodes," "lock apple watch automatically", "configuring notification privacy ". 
Following the provision of security measures, the chatbot interface prompted the user to ask any related questions.
The chatbot was then engaged with two user prompts: "Can I adjust the number of failed unlock attempts to 5 failed unlock attempts?" and "Can I hide notification details just from specific contact?". The chatbot responded accurately and comprehensively to both queries, providing detailed, step-by-step instructions and explanations, demonstrating its ability to deliver context-aware support.
Case 2: Apple HomePod Mini
In the second test case, an image of the Apple HomePod Mini was uploaded. Anveshan again accurately identified the device and generated a set of security recommendations specific to the HomePod Mini, such as, "turning off location services on home pod," "limit ad tracking through device settings","keeping the app regularly updated". This result confirms the system's consistent performance across different device categories.
Case 3: D-Link Wireless Router
Finally, an image of a D-Link wireless router was
 uploaded. The system successfully recognized the router and provided relevant security measures, including "changing the default admin password," "disabling 
wps
", "disabling remote management". This test highlights Anveshan’s ability to handle network devices, 
demonstrating
 its broader applicability in securing diverse IoT and networking components.
Summary of Results:
These three test cases demonstrate Anveshan’s core functionalities:

 device identification through image analysis, provision of tailored security recommendations, and interactive chatbot support. The system consistently recognized different device types and delivered relevant security measures. The chatbot effectively addressed user queries, providing detailed and context-aware responses. Conclusion
This research presented Anveshan, an innovative web application designed to democratize device security through the integration of AI-powered image recognition and a conversational chatbot. By leveraging the Pixtral model for accurate device identification and a fine-tuned Mistral LLM for generating tailored security recommendations and engaging in interactive dialogue, Anveshan simplifies the complex process of securing networking and IoT devices. The system's user-friendly interface, built with Streamlit, ensures accessibility for individuals with varying technical backgrounds, thereby empowering a broader audience to enhance their digital security posture.
The results obtained from testing Anveshan with diverse device types, including an Apple Watch Series 6, an Apple HomePod Mini, and a D-Link wireless router, demonstrate the system's effectiveness in accurately identifying devices and providing relevant, context-aware security measures. The chatbot's ability to respond to user queries with detailed and informative answers further validates Anveshan's potential as a valuable tool for simplifying device security.
Future work will focus on expanding the device dataset to encompass a wider range of devices and vulnerabilities, further improving the accuracy and comprehensiveness of the security recommendations. Additionally, we aim to explore the integration of real-time threat intelligence and automated security configuration features to enhance the proactive security capabilities of Anveshan.
